# 按模式记忆窗口

日计划、收集箱、日历、专注分别保存窗口位置、普通窗口大小与最大化状态。切换视图时先保存当前模式，再恢复目标模式；再次启动仍从日计划进入，并恢复日计划的窗口。设置与数据工具沿用所在视图的窗口。

- 移动、缩放、切换视图、关闭及完全退出时保存到本地 SQLite。
- 首次进入日历默认 1080 × 720，其余模式默认 480 × 720；首次使用时沿用当前窗口位置。
- 已有安装尚无分模式记录时，将原主窗口布局作为日计划布局。
- 恢复时使用目标位置附近显示器的可用区域，处理负坐标、多显示器和显示器断开，避免窗口无法触达。
- 最大化保留最近的普通窗口矩形；最小化和系统全屏的临时尺寸不会覆盖该矩形。全屏内切换模式，在退出系统全屏后恢复对应布局。
- macOS 原生窗口就绪后再精确恢复，避免初始化尺寸偏差在多次启动后累积。

实现使用现有 `window_states` 表中的 `view:day`、`view:inbox`、`view:calendar`、`view:focus` 记录，不新增表。主窗口置顶、透明度等全局设置继续存于 `main`，不随视图变化。分模式记录随完整数据库备份保留。

原生事件的取样与模式切换均在 UI 线程串行执行，延迟的移动/缩放回调读取当前窗口及其模式，避免跨模式写入错误的布局。

验证覆盖独立记录、数据库关闭重开、最大化的普通窗口矩形、首次使用、负坐标与小屏幕边界。macOS 使用独立验收数据验证模式切换、系统移动/调整大小、最大化和重启；Windows 完成编译检查，原生界面需在 Windows 上补验。
