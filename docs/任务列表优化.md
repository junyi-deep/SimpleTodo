# 任务列表优化

本轮规则优先于早期设计中的无限层级、内嵌改期面板和 macOS 交通灯保留规则。仍沿用紧凑黑白灰、单一主窗口与本地 SQLite 数据。

## 列表与层级

- 根任务为第 1 层，最多 5 层；第 5 层不再允许添加子任务。新增、缩进、重挂父节点、跨根拖动、复制和导入均由后端验证最终整棵树，超限事务回滚，保留原任务。单根最多 200 个后代的容量限制不变。
- 历史版本已有的超深任务不删除、不自动改变父子关系。允许编辑、完成和缩浅；现存节点不能变得更深，新节点仍受五层限制。复制、导入和新重复实例必须符合五层限制。
- 展开箭头使用独立 `rotate` 动画，与通用按钮的缩放反馈分离。箭头、完成框和标题首行对齐，长标题换行后仍固定在首行。
- 双击和键盘进入标题编辑时聚焦行末，不选中原文。输入框透明、无高亮边框；保留行的键盘焦点提示、输入法保护、Enter 保存、Esc 取消和冲突时保留草稿。
- 完成任务的标题使用删除线与次要文字颜色，浅色/深色主题均适用。
- “调整计划日期”和“移动到其他父任务”改为主窗口内的模态对话框，背景列表位置保持不变。Esc/取消关闭并恢复任务焦点。

## 拖动

参考 [SortableJS 的嵌套排序示例](https://sortablejs.github.io/Sortable/)及[交换阈值说明](https://github.com/SortableJS/Sortable/wiki/Swap-Thresholds-and-Direction)，采用指针驱动的预览与明确落点分区；没有引入额外排序库修改 Vue 管理的 DOM。

- 鼠标从拖动柄移动超过 5px 后启动；浮动行跟随指针，源行淡化。
- 上四分之一插到目标前、下四分之一插到目标后、中央移入目标成为子任务；Alt 强制前置。跨根拖到子任务边缘同样保留同级插入意图。
- 插入位置显示细线，移入目标显示灰底与轮廓；接近列表上下边缘自动滚动。松手后预览以 180ms 回落淡出，列表同级位置沿用 240ms 平滑重排。
- Esc、指针取消和窗口失焦撤销当前拖动，不写入数据库。越界结构、循环、容量和版本冲突由事务拒绝并提示。
- 拖动仍调用现有排序/移动服务，保存完整分支、祖先状态和手动顺序，刷新后结果不变。

## 日计划时间轴

参考 [Motion 平滑标签切换示例](https://motion.dev/examples/vue-smooth-tabs)与[布局动画说明](https://motion.dev/docs/layout-animations)。选中日期由连续滑块表示，280ms 指数缓出；任务区域按日期前进/后退方向做 14px 轻移与淡入。快速连续选择从当前滑块位置接续，避免跳回起点。窗口缩放后重新测量落点。

动效接入现有 Motion 执行器；关闭应用动画或系统开启“减少动态效果”会立即完成运行中的动画，直接显示最终状态，不影响点击、编辑与保存。

## 窗口控制

主窗口设置 macOS 原生最小化、放大和关闭按钮为隐藏，清除其左侧预留空间。应用自定义的最小化、放大/还原、固定、更多与关闭按钮保留；Windows 继续采用无系统标题栏窗口。
