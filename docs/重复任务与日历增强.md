# 重复任务与日历增强（v0.1.4）

本轮规则优先于旧文档中的 Enter 编辑、保存后停止录入和日历选区行为。

- 单击任务标题继续原位编辑。Enter 保存并在当前任务后面创建同级草稿，根任务和子任务都适用；Shift+Enter 保存后创建子任务。输入法组合确认不提交，空白草稿或 Esc 不创建记录。点加号仍可从列表末尾开始录入，取消后只保留柔和的焦点底色。
- 创建同级任务与插入顺序在同一 SQLite 事务提交，失效的同级定位回滚，命令编号重试不重复插入；子任务遵循五层和容量限制。
- 年/月自定义下拉展开时定位到当前选中项，支持方向键及 Esc。周视图变更年/月也会跳转到对应日期范围。
- 日期抽屉从右侧完整滑入，关闭时滑出；系统减少动态效果或应用关闭动画时立即完成。
- 拖动任务时，目标日期以蓝色底色及内框提示落点；在网格左右边缘停留约 650ms 后自动翻页，月视图翻月、周视图翻周，继续停留可连续翻页。Esc 取消并清理预览与目标状态，不改变日期。
- 日历拖选连续日期，Shift 点选扩展范围，⌘（macOS）或 Ctrl（Windows）点选增减不连续日期；多选时保持网格可操作。在选区内右键选择“创建重复任务”，默认按所选日期对应的星期每周重复。选中两个不同星期的日期会成为每周两次，而非只生成两条一次性任务。
- 重复任务支持每日、每周、每月，间隔 1—99；默认一直重复，结束日期留空。可设置开始日期、结束日期（含当天）和每次提醒时间；每周的首次任务落在开始日期及以后第一个符合规则的星期。每月遇到缺失日期时使用月末。任务详情也能把普通任务设置为重复任务。
- 新任务与重复规则原子保存，重复实例按查询范围逐步生成，不预先无限创建；单次完成、跳过及后续修改保留原有语义。重复任务不自动延期，日历单次拖动入口保持禁用，避免无意修改整个序列。

## 验证

- Go 全套测试与 go vet 通过；新增同级插入事务/回滚/重试和重复日期范围测试通过。
- Vitest 9 项、Playwright 46 项全部通过（新增 6 项专项）：年/月选项可见、Esc 后加号无轮廓、根/子任务同级插入、无限/有限重复、跨月和翻周、组合框聚焦时 Esc 取消拖动、减少动态效果与周历年月切换。
- macOS arm64 生产应用包构建与临时签名校验通过；Windows amd64 生产交叉编译通过。
- macOS 原生使用独立临时数据库验收 Enter 连续同级录入、Esc 取消空白草稿、年/月下拉定位、Command 多选、右键创建与抽屉保存。SQLite 核对每周一/三规则、开始日期 2026-10-26、结束日期 NULL，以及 10 月 26/28 日、11 月 2/4 日实例；返回清单与退出验收实例正常。
- 独立界面复核结论为 ship，限定于提供截图、实现与测试证据的增量范围；静态截图不独立证明动画过程。Windows 原生 GUI 未实测。
