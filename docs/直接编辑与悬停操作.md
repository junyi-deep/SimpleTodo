# 直接编辑与悬停操作

本轮规则优先于早期文档中的单击选中、双击编辑、任务更多菜单和分支聚焦规则。

- 单击任务标题或行的空白区域直接进入原位编辑，光标在末尾；Enter/失焦保存、Esc 取消。编辑中 Shift+Enter 先保存，再直接进入添加子任务；输入法组合期间不误提交。
- 展开箭头始终保留 12px 列位，叶节点不再撤掉占位；每层缩进 22px，避免父子复选框重合。完成统计与操作按钮统一 23px 首行高度。
- 搜索占满工具条剩余宽度。搜索、标题与新增子任务输入不显示突兀的边框/阴影；任务行键盘焦点使用细轮廓。
- 任务右侧更多菜单、分支聚焦、面包屑导航与移到收集箱操作已移除。改期（子任务为更换父任务）与删除直接显示在操作区；缩进/提升仍通过 Cmd/Ctrl+[、] 操作。
- 操作区在鼠标悬停时从右滑出，键盘聚焦操作按钮时也可访问；离开后隐藏。提醒为琥珀色、编辑为蓝色、日期为紫色、删除为红色，深色主题有对应配色。按钮宽高 23px、间距 0；顶栏按钮也收紧。
- 第一次点击删除会变为绿色对钩，第二次点击删除任务及其完整子树。Esc、点击其他位置或 4 秒超时取消确认；确认期间保留操作入口，不再额外弹出删除窗口。
- 标题、新增任务和新增子任务输入会在光标附近产生短暂星星。粒子忽略输入法中间组合、适配多行光标，最多 80 个；不抖动窗口、不拦截鼠标和输入。关闭应用动画或系统启用“减少动态效果”时停用，并清理运行中的效果。
