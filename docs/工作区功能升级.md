# 工作区功能升级

本文记录当前功能和兼容规则，优先于旧设计中关于单窗口、手动检查更新以及每日／每周／每月重复配置的描述。

## 任务时间与每日完成

- 每个主任务与子任务均记录创建时间、内容更新时间、完成时间，以及开始时间和可选结束时间。普通新增默认在计划当天开始、当日 23:59:59.999 结束；日历选定其他日期时使用所选日期，多日范围创建使用所选起止日。手动清空结束时间才持续展示。切换到未来日期只查询，不提前触发自动延期。
- 新任务开始时间默认创建时刻；在指定日期新增时，使用该日期和当前时刻。未设置结束时间时持续显示；设置结束时间后仅在日期范围内显示。
- 整项任务完成时记录结束时间并停止后续安排；已完成条目下显示“创建时间 ~ 完成时间”。父任务未完成时，后续日期（含自动延期后）继续展示已完成子任务，并保留完成状态及原完成时间。父任务结合未完成的当前与未来子任务聚合完成状态。
- 标题、描述、标签、起止时间和提醒内容变动才更新内容更新时间。勾选、排序和层级调整不会仅因版本号变化而改写该时间。
- 开启自动延期后，过期且仍有未完成记录的任务延长结束时间到今天，不搬走历史日期，不重置历史完成记录。手动删除主任务会终止后续展示；保留已完成历史。
- 编辑、增加或删除子任务会更新当天与未来的任务结构；历史完成记录保留。已完成父任务可以编辑，增加待办子任务后重新成为未完成。
- 界面不再提供周期配置。为兼容旧备份，数据库内部仍使用每日规则和每日快照；旧每周／每月任务后续按每日生成，已有历史不改写。升级前生成保护备份。旧已完成的普通任务保留为有限历史记录。

## 标签和过滤

预置“重要”“紧急”。条目右侧标签按钮支持搜索、新增、多选；设置中的标签页支持重命名、删除和调整顺序。删除标签会清理条目、未来模板和过滤偏好中的引用。

展开层级菜单中的“显示标签”默认关闭。过滤菜单支持完成状态和多个标签；标签之间为“任一匹配”，保留匹配的子任务及其祖先。日计划和收集箱分别持久化过滤状态。日计划默认显示已完成，收集箱默认隐藏已完成。

## 独立窗口

列表、日历、专注、设置、复盘各有独立原生窗口，可以同时打开。每个窗口分别保存正常尺寸、位置及最大化状态；重新打开和重启恢复，超出当前屏幕时校正到可见区域。日计划和收集箱共用列表窗口。

标题栏按钮打开或聚焦对应窗口；关闭按钮隐藏当前窗口，后台提醒继续。完全退出时依次检查各窗口的未保存内容；取消任一确认则保留应用与草稿。设置中的外观页可选择目标窗口调整显示层级、不透明度，或重置窗口位置。

## 日计划与日历

- 今天有加粗描边；拖动时间轴时描边与日期一起移动。跨午夜后日计划自动跟随新一天，正在编辑或拖动时等待操作结束。
- 月历和周历的子任务显示默认关闭，可通过开关启用并持久化。日期抽屉继续支持新增、就地编辑、标签和任务设置。
- 甘特图以任务范围为横条，默认展示主任务；拖动横条整体改期，拖动左右端点调整起止时间。没有结束时间的任务显示持续标记；设置结束端点后成为有限范围。
- 甘特图支持横向滚动、前后时间段切换，焦点横条可用左右方向键移动。保存失败显示错误并保留重试路径。

## 复盘与 NOTE

复盘窗口左侧为“首页”“复盘”。时间范围默认本年 1 月 1 日开始，结束可空；默认不统计子任务。

首页展示任务总数、完成数、完成率、完成热力图、最近 14 天完成趋势和标签分布。范围过滤按任务当天计划日期，热力图按实际完成日期统计。

复盘页左侧任务报告可按时间、状态、标签、标题／描述模糊搜索以及是否包含子任务筛选。右侧 NOTE 列表支持搜索、新建、编辑、删除；分栏可拖动调整比例。NOTE 标题必填，显示创建与更新时间，内容支持 Markdown 编辑和预览；保存冲突会提示重新载入，不静默覆盖。预览禁止原始 HTML 执行，外部链接经系统浏览器打开。

## 备份保留

自动、手动、升级和恢复前保护备份合计保留最近 3 次成功备份。旧逻辑只清理自动备份，其他类型会不断累积；现在统一按备份文件时间排序，在备份成功后及每日检查时清理。失败的备份不会挤掉已有可用备份。恢复前先复制并校验所选文件，再生成保护备份，因此恢复源即使因保留上限被清理，恢复仍可完成。

只清理应用命名规则管理的备份，用户自行命名的数据库文件不删除。完整 SQLite 备份包含任务历史、标签、笔记和设置。任务 JSON 导出包含标签名称及顺序，导入时按标签名合并并重映射引用；NOTE 不包含在任务 JSON 中，需要完整数据库备份。

## 版本检查

应用启动、重新进入列表以及后台每小时检查 GitHub 最新 Release。窗口之间共用单一检查器，短时间重复进入会合并检查。沿用系统／无代理／自定义 HTTP 代理设置，代理凭证不要求填写。

发现新版本时聚焦列表窗口并使用应用组件弹窗，提供“立即更新”“跳过此版本”。跳过状态持久化，不再提示同一版本；后续更高版本仍会提示。自动检查失败保持安静，手动检查显示错误。安装重启前依次检查各窗口的未保存内容，取消则保留草稿和原应用。更新仅请求固定 GitHub 发布信息及安装包，不上传任务、标签、笔记或日历内容。

## 实现边界

任务树仍只使用 `tasks` 表，最多 5 层；新增 `starts_at`、`ends_at`、`tags_json` 及范围索引。标签和 NOTE 分别保存于 `tags`、`notes`，NOTE 使用乐观版本控制。迁移版本为 3，保留旧版本校验与备份恢复能力。

原生文件选择窗口、日期选择器和系统通知授权仍使用操作系统能力；应用内确认与提示使用组件弹窗。本机日历继续只读，遵循此前平台支持范围。

## 本轮验证

2026-11-01：82 项浏览器界面回归、9 项前端单元测试、前端类型检查与生产构建、全部 Go 测试、`go vet` 和 Go 竞态检查通过。另增独立设置窗口延迟加载回归，验证已保存的专注时长、显示层级与不透明度能够正确初始化；原生确认专注时长显示为保存值。新增后端用例覆盖统一备份保留与恢复源保护、迁移、每日独立完成、子任务范围、内容时间戳、层级变化在后续日期保持、标签导入导出、NOTE 版本冲突及重启检查取消。

Windows amd64 已通过编译检查；这不代表 Windows 原生交互已验收。macOS 原生已验证五窗口独立打开、隐藏窗口保留笔记草稿、取消退出保留内容，以及真实退出／重启后五窗口的尺寸、位置和最大化状态一致。验收发现并修复了隐藏窗口启动时丢失最大化状态的问题：先以正常边界创建窗口，放置完成后再最大化，确保还原仍回到原尺寸。本轮测试均使用隔离临时数据库，没有修改用户正式数据；未执行真实应用替换升级。
