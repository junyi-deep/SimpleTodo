# 更新代理与动效

## 界面调整

标题栏操作顺序为：任务列表、日历、专注、固定、更多、最小化、放大/还原、关闭。关闭按钮在 macOS 和 Windows 均可用，继续沿用关闭主窗口后后台运行的行为。

关于页明确“所有任务数据仅存放在本地电脑上”，移除使用提示及技术组件说明。

## 更新代理

在设置 → 关于 → 发布与更新选择：

- 系统代理：默认值，读取 macOS / Windows 系统代理配置；启动环境显式设置代理变量时沿用其优先级。
- 无代理：忽略系统与环境代理，直接连接。
- 自定义代理：HTTP 地址，可填写 `http://127.0.0.1:7890` 或 `127.0.0.1:7890`。用户名、密码均可留空；HTTPS 更新请求通过 HTTP CONNECT 隧道传输。

只接受 HTTP 代理，不接受 HTTPS/SOCKS 代理地址。检查更新与下载前会保存当前代理表单，也可单独点击“保存代理设置”。密码已保存时不回传给界面，留空保留，可单独清除。修改代理不会改变系统代理设置。

代理配置保存在应用配置目录的 `update-proxy.json`，与任务数据库、任务导出和数据库备份分开；测试隔离目录下使用独立配置。文件原子写入，macOS 权限为仅当前用户可读写；Windows 沿用用户配置目录权限。密码保存在该本地文件中，不声明为系统凭据库加密存储。网络错误提示不包含代理凭据。

更新来源仍固定为本项目 GitHub 最新稳定 Release。安装包通过应用自身 HTTP 客户端下载，并复用同一代理策略；保存位置由系统保存对话框选择。下载先写同目录临时文件，成功后替换目标，失败时保留原文件并清理临时文件；检查请求超时 20 秒，下载超时 10 分钟，最大 512 MiB。下载后由用户自行安装，不自动安装。

## 动效设计与实现

使用 `motion` JavaScript 库，复用统一 Motion 执行器与 Vue 过渡组件；不改变黑白灰主题或任务密度。

| 操作 | 反馈 | 时长 |
| --- | --- | --- |
| 完成任务 | 对钩逐笔出现，勾选框轻微放大后回位 | 260–280 ms |
| 所有任务完成 | 底部显示双对钩和“都完成了” | 200 ms |
| 新增、展开子任务 | 任务内容从左到右揭示 | 200 ms |
| 删除、折叠子任务 | 淡出；退出立即停止接收交互 | 120 ms |
| 任务重排 | 同级任务平滑让位，拖动柄命中区域保持不变 | 240 ms |
| 列表日期、日历周期、设置分类、专注模式 | 短距离位移与透明度过渡 | 200 ms |
| 菜单、自定义下拉 | 轻微缩放展开，关闭淡出 | 200 / 120 ms |
| 任务详细设置 | 对话框轻微缩放进入，关闭淡出后恢复焦点 | 200 / 120 ms |
| 日期任务抽屉 | 从右侧滑入 28 px，关闭向右退回 18 px | 280 / 120 ms |
| 按钮、固定、视图、翻页等图标 | 按下图标轻缩后回位，按钮本身保持原位 | 200 ms |
| 提醒气泡、通知面板、导入导出、完成统计与提示 | 有限、单次的进入或状态变化反馈 | 200 ms |

没有增加持续播放的装饰动画、声音、远程资源或逐条等待的开场动画。用户关闭动态效果或开启系统“减少动态效果”时，立即完成运行中的 Motion 动画，CSS 重排过渡也停用；任务状态、勾选和文字反馈仍立即可见。卸载和快速反复操作会取消旧动画，避免遗留透明度、位移或不可见内容。
