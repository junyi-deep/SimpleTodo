# 列表过滤与排序优化

本轮行为优先于旧说明中“重复图标”和缺少过滤入口的描述。

- 工具条提供过滤图标和选择图标。过滤气泡包含“显示已完成的任务”和“显示周期任务”，日计划与收集箱分别记忆，两项状态写入 SQLite 设置表。首次使用时日计划显示完成项，收集箱隐藏完成项；两个视图都显示周期任务。过滤只改变显示，不更改任务状态、日期或重复规则；隐藏根任务时整棵子树一并隐藏。
- 清单仅未完成任务可排序。悬停显示同级上/下移按钮，首项仅下移，末项仅上移，单项不显示；子任务保持同级和父级。收集箱跨日期排序不改日期。
- 指针排序时插入与任务行同高的占位间隙，通过 Motion 展开，后续任务实际让位。展开分支的“之后”落点在完整可见后代之后，预览和提交一致；拖到列表下方空白处，根任务排到当前列表末尾，子任务排到当前父任务的子任务末尾。Esc、取消、失焦或结束拖动会移除占位。任务中部仍可用于嵌套，最多五层。
- 重复信息在标题下以小字显示，包含周期、间隔、每周星期或每月日期，以及持续重复或截止日期；移除单独重复状态图标。提醒信息仍保留在标题下方。
- 调整计划日期弹窗中的长标题自动换行，窄窗内不再产生横向滚动条。
- 原生窗口允许透明背景；页面将保存的背景不透明度应用到背景表面，文字不随之变淡。滑条即时预览，“应用窗口设置”后保存；离开设置取消未应用的预览，固定窗口保留当前不透明度。默认 100%。应用内模态弹窗继续使用实色背景以保证可读性。
