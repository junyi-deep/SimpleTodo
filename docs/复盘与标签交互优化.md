# 复盘与标签交互优化

本次根据用户标注的桌面截图，调整复盘首页、任务总览及任务行标签反馈。沿用现有黑白灰浅深主题、系统字体、紧凑控件和独立窗口，不新增调色板、字体或全局设计 token。热力图、最近两周趋势和标签分布按用户明确选择保留，只调整布局。

## 任务总览

- 原任务报告标题改为“任务总览”，标题旁显示当前匹配数量。移除报告上方重复标题区与多余留白，让任务总览和右侧 NOTE 从同一高度开始。
- 开始日期、结束日期与“统计子任务”放入左侧报告区域，紧邻内容搜索、状态和标签筛选；筛选不再横跨笔记区域。
- 标签筛选改为可搜索的多选下拉浮层，触发器显示“全部标签”或已选数量。多个标签按任一匹配筛选；支持取消选择、清除筛选和无匹配提示。
- 浮层独立定位，打开或搜索时不推移报告内容；Escape 关闭并恢复触发器焦点，外部点击、焦点离开、窗口缩放或外部滚动也会收起。
- 右侧笔记继续保留搜索、新增、编辑、预览、保存、删除、未保存离开确认及分栏宽度持久化；本次未改变这些行为。

## 首页统计

“任务统计”标题下集中放置日期范围、任务状态和子任务开关。统计遵循当前日期、状态与子任务范围，任务总览中的内容搜索和标签选择不限制首页统计。

原大数字摘要改为真实的已完成／未完成饼图，旁边显示总数、两类数量和完成率。饼图使用现有中性色；全部完成或全部未完成时绘制完整圆，零任务时显示中性空圆，数量和完成率保持零值，不伪造扇区。图形提供包含实际数量的可访问名称。

饼图与完成热力图并排，最近两周趋势和标签分布继续放在下方。窄于 660px 时上方统计区域转为单列；热力图保留按实际完成日期计数的规则，标签分布保留真实标签数量与无数据提示。

## 任务行标签反馈

全局“显示标签”关闭时，当前选中的任务、打开标签选择器的任务，以及批量选中的任务仍显示已分配标签。标签在标题下以现有小字样式呈现，勾选后立即更新。打开标签选择器同时选中所属任务；离开选中状态后，其他任务继续遵循全局显示偏好。

标签选择器保留搜索、新增和多选；标签从实时任务状态读取，避免保存后仍显示旧值。标签分配继续持久化，重新加载后仍能读到。Escape 可在保存造成输入失焦时收起选择器，并将焦点交回所属任务的标签按钮。

## 实现与视觉一致性

实现位于 `frontend/src/components/ReviewPanel.vue`、`TagFilter.vue`、`TaskTree.vue`、`TagPopover.vue`；外观规则位于 `frontend/src/styles/visual-system.css`，颜色仍取自 `frontend/src/style.css` 的现有变量。新增回归位于 `frontend/e2e/review-refinement.spec.ts`。

对照 `PRODUCT.md`、`DESIGN.md` 和 `.impeccable/design.json`，本次继续使用 Quiet Neutral Workstation 的灰阶表面、系统字体、细分隔和轻量浮层；统计扇区复用 accent／border-strong，浮层复用 surface、overlay 圆角及 shadow-popover，任务标签继续使用中性小字。没有把页面专用饼图尺寸、标题间距或选中标签例外扩展成全局规则。

`DESIGN.md` 与 sidecar 保持原样。其中原有复盘标题／数字摘要尺寸、布局说明和“标签默认隐藏”的概括仍是此前记录；本次局部标题、饼图和选中标签例外以本文及实际组件为准。该记录差异未用新增 token 或重写既有系统消除；本次检查未发现需要另行修复的既有配色或字体漂移。

## 验证与范围

全部 87 项端到端回归、9 项前端单元测试、类型检查和前端生产构建通过。新增回归覆盖标签即时显示与持久化、日期／状态／子任务共同筛选、饼图零值及完整圆、标签搜索多选、报告不位移、Escape 焦点恢复、外部与缩放关闭、浅深主题及横向溢出。

已检查隔离演示数据下的截图：1072×712 浅色首页、带标签浮层的任务总览和零数据状态；800×720 深色首页；900×720 深色任务总览；400×740 选中任务标签。独立视觉复核结论为可交付，无需追加实质修正。

macOS 原生 1080×720 深色窗口已验证首页、任务总览、自定义标签搜索与勾选，以及 Escape 后的焦点恢复；原生清单还验证了全局标签关闭时选中任务立即显示标签、分配“紧急”后即时反馈，以及保存导致失焦后仍可 Escape 收起。最终 macOS 包构建与严格临时签名校验通过，Windows AMD64 Go 构建通过；未进行 Windows 原生 GUI 验收。

全部演示与原生检查使用隔离 QA 数据，未访问或修改用户正式任务数据。本次未改变任务数据模型。
