# 开发与发布

界面改版基线见 [界面改版](界面改版.md)。生产程序为单窗口，不启动浏览器预览 HTTP 服务。

依赖：Go（版本见 go.mod）、Node.js 24、Wails CLI v3.0.0-beta.33。前端为 Vue 3 / Tailwind CSS 4 / Pinia；SQLite 为持久化存储，根和所有子节点在 tasks 单表中。

```sh
cd frontend && npm ci && npm run build
cd ..
go test ./...
go test -race ./internal/todo
go vet ./...
wails3 task darwin:package ARCH=arm64
wails3 task windows:build ARCH=amd64
```

前端检查：在 frontend 下执行 `npm run typecheck`、`npm test`、`npm run test:e2e`。端到端测试自动启动临时真实 SQLite 和本机预览 API，数据与用户目录隔离。`SIMPLETODO_DATA_DIR` 供原生测试指定独立数据目录。

`.github/workflows/release.yml` 在任何标签推送时构建 macOS arm64 和 Windows amd64，两个平台均成功后发布 Release，附件恰为两个 zip。手动 workflow_dispatch 只运行构建验证，不发布。Actions 引用固定提交；Wails CLI 固定到与 go.mod 相同版本。

macOS 使用 macos-15 的 arm64 runner，并校验 uname；Windows 在 windows-2022 上构建。macOS 应用包执行 ad-hoc 签名，不宣称 Developer ID、公证或 Windows Authenticode 签名；需要正式证书时另行配置。
