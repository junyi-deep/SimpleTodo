# 标签与日历过滤修复

对应 [issue #7](https://github.com/junyi-deep/SimpleTodo/issues/7)，纳入 v0.2.2。

## 标签选择

标签选择组件通过 Teleport 和 HTML Popover 顶层显示，避开任务行、列表滚动区和动画容器的裁切。宽度最多 240px，距窗口边缘至少 8px；根据按钮上下空间决定展开方向，最高 360px。搜索栏固定在选择框内，选项超过空间时独立滚动；搜索和新增后重新计算位置。

保留多选、搜索、新增、外部关闭和 Escape 返回触发按钮。滚动选项不关闭弹层，滚动所属任务列表则关闭；在日历抽屉内选择标签不会关闭抽屉。

## 标签颜色

设置的标签页增加颜色下拉，使用现有自定义下拉组件，可选择灰、红、橙、金、绿、青、蓝、紫八种颜色。新标签默认灰色，“重要”默认红色，“紧急”默认橙色。颜色随标签保存，任务标题下、标签选择、筛选和复盘报告共用填充色；文字根据填充亮度选择白色或深色，保持可读性。应用主控件仍使用原有中性色。

SQLite 新增迁移 `004_tag_colors.sql`：只为 `tags` 增加 `color` 字段，不改变任务结构。升级前创建保护备份；迁移带校验记录。颜色支持随数据库备份恢复和任务 JSON 导入导出；旧 JSON 缺少颜色时使用默认色，旧调用保存时缺少颜色会保留已有选择。合并导入遇到同名标签时保留本机定义及其颜色。后端校验颜色为六位十六进制值，拒绝不合法的写入和导入。

## 日历完成过滤

日历工具栏增加“已完成”开关，月历、周历、日期抽屉和甘特图共用 `calendarShowCompleted` 设置。默认关闭，主任务和子任务都遵循筛选，重启后保留选择。此设置独立于日计划和收集箱；本机只读日程不受任务状态开关影响。
