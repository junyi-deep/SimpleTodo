> 2026-10-21 更新：单窗口、黑白灰、全量收集箱、行内编辑、自定义下拉和日历右抽屉以 [界面改版](界面改版.md) 为准；下文的多窗口、颜色入口及未完成页签描述已被该方案替代。

文档日期：2026-10-20。状态：设计基线，已完成首轮实现；功能入口、运行方式与验证范围见 [项目说明](../README.md)。

关联文档：[功能设计](功能设计.md)、[开发实现设计](开发实现设计.md)。功能编号是三份文档与后续开发任务的共同索引。

## 1. 产品目标与边界

使用 Wails 3、Vue 3、Tailwind CSS 4、Pinia 和 SQLite，制作一款个人本地桌面待办应用。以按天规划、多级任务拆分、快速记录和桌面常驻为核心体验。**macOS 优先验收，兼顾 Windows；Linux、移动端和浏览器部署不在本轮范围。**

无需账户、登录和在线服务即可完成任务管理。业务数据只保存在本机；手动导入、导出和备份属于本地文件操作，不属于同步。

应用统一使用 SimpleTodo 的名称、图标及资源；界面、交互和数据规则由本项目文档定义。

## 2. 范围与优先级约定

功能清单定义交付范围，《功能设计》约定字段、默认值、操作流程与异常行为，《开发实现设计》落实技术架构与验收方法。三份文档共同构成 SimpleTodo 的开发依据。

任务数据采用统一节点模型，根任务与所有层级子任务只保存在 tasks 一张任务表中；通过直属父节点和根节点关系组织树，表索引与约束配置见《开发实现设计》第 4 节。

优先级表示开发顺序，不表示删除范围：P0 为日常任务闭环；P1 为完整业务能力；P2 为桌面增强和体验收尾。**P0、P1、P2 均属于本次规划的交付范围**；平台受限项按兼容矩阵验收并显式显示实际能力。

## 4. 明确排除的内容

| 排除项 | 不建设的内容 |

| 所有同步能力 | WebDAV、云端数据库、多设备同步、同步账户、远程配置、冲突合并、同步配置导入导出 |
| 所有 AI 能力 | AI 周报、任务拆解、模型配置、自定义 OpenAI 接口、提示词、API Key 存储 |
| 在线账户及协作 | 登录、注册、团队、共享清单、任务分配、评论 |
| 在线依赖 | 后台遥测、在线节假日查询、远程字体、运行时 CDN、自动检查更新 |
| 额外产品体系 | 项目看板、复杂标签体系、附件系统、插件市场、日历双向集成、统计报表 |
| 第三方私有格式兼容 | 直接读取外部应用的私有数据库、二进制备份和内部剪贴板格式 |

重复待办“修改整个系列”是本机业务规则，不是数据同步。用户主动备份到文件或手动搬移文件也不构成应用同步功能。

## 5. 交付顺序与完成标准

| 阶段 | 交付结果 | 对应范围 |
| --- | --- | --- |
| M0 技术与平台验证 | macOS 可运行的原型验证记录，SQLite 事务及迁移策略确认，Windows 关键能力兼容清单 | F17、F26、F28、F29、F33 的前置验证 |
| M1 日计划闭环 | 日期、收集箱、所有未完成、任务编辑、颜色排序、基础主题和驻留，重启不丢数据 | F01—F08、F26—F27、F30—F31 基础、F33 |
| M2 完整业务 | 多级子任务、重复、延期、提醒、总览、浮窗、专注、倒计时和数据导入导出/备份 | F09—F14、F16、F19—F24 |
| M3 桌面增强与发布 | 节假日、窗口增强、贴边隐藏、迁移、快捷键、自启、外观收尾、更新入口和双平台验收 | F15、F17—F18、F25、F28—F32 |

完成的判断依据是数据持久化、核心异常可恢复和操作行为符合《功能设计》，不能只以页面可见作为完成。平台限制须经过验证后给出降级结果；未实现的通用业务功能不能以“跨平台差异”为由略过。

### 关键验收场景

1. 断网启动，创建普通任务、收集箱任务及至少三级子任务；退出重开，内容、层级、同级顺序、颜色与状态一致。
2. 日计划、总览、浮窗同时打开；任一窗口勾选或改期，其他窗口最终一致，不产生重复任务。
3. 重复任务逐日独立完成；删除单次不会重新生成；修改后续不会篡改历史完成记录。
4. 跨零点、离线数天后启动或系统休眠恢复，普通任务按规则延期，重复任务不延期，提醒不会连续轰炸。
5. 长时间专注在窗口隐藏/关闭主界面期间仍正确计时；重启可恢复状态；完全退出期间不承诺准时提醒。
6. 导入前能看到树形预览；导入失败无部分脏数据；复制、导出及恢复保留多级父子关系与同级顺序。
7. 提醒权限被拒绝、全局快捷键冲突、数据目录只读或磁盘不足时，有可理解的错误与可执行的处理方式。
8. macOS 菜单栏、红色关闭按钮、Cmd 快捷键和通知可用；Windows 托盘、关闭窗口、Ctrl 快捷键和通知分别通过实机验收。
9. 完成任意分支会完成整棵子树，并逐级更新祖先；取消叶节点只影响祖先与本节点，不重置兄弟分支。层级调整禁止循环，删除分支前明确提示后代数量。

## 6. 待后续实测收敛的事项

- SimpleTodo 的窗口尺寸、树形缩进、深层级导航、动画和快捷键在目标设备上的可用性与可访问性。
- 桌面置底与背景透明度在 macOS Spaces、全屏应用和 Windows 多屏下的能力；不承诺穿透锁屏或系统安全界面。
- 正式发布的最低 macOS 版本、Windows 10/11 的支持矩阵、签名与分发方式；M0 记录验证环境后固定。
- 节假日数据包维护来源与覆盖年份、项目发布页地址。缺失时保留明确空状态，不填充虚构内容。
