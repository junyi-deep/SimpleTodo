## 独立界面复核

八张截图均有效，detector 返回 `[]`。复核唯一的实质问题“切换或关闭抽屉静默丢失编辑草稿”已修复，回归覆盖取消/确认两条路径；复核结论 `disposition: ship`，范围仅限该修复与截图回归，不代表原生 OS 能力全项通过。

本轮原生 GUI 验收工具报告 Mac 锁屏，已请求解锁；不以本机编译、浏览器截图或 GitHub runner 构建替代原生窗口按钮、实际缩放、通知、托盘或登录启动验收。
