## macOS 原生补验

解锁后，使用独立临时 SQLite 数据目录完成窗口缩放、返回列表、放大/还原、最小化/恢复、固定开关、周视图、自定义下拉键盘选择、日期抽屉 Esc 关闭、中文任务录入、Shift+Enter 子任务录入、Enter 行内编辑及 Esc 恢复父任务焦点。原用户待办未改动。

修复三项原生环境问题：

- 日历扩大时可能超出屏幕右边；现使用屏幕管理器提供的 DIP 工作区约束窗口，适配 Retina 与负坐标显示器；小屏工作区会相应缩小窗口。
- Safari 不会默认让鼠标/辅助功能激活的按钮聚焦；自定义下拉打开后显式聚焦，End + Enter 已在原生周视图切换通过。
- WebView 的 tree 语义隐藏了行内详情表单；改用列表与命名任务分组，保持快捷键和视觉层级，原生 AX 已实际读取标题、描述、日期、重复及保存/取消按钮。

另外原生确认面板已验证：切视图时提示未保存草稿，Esc 取消后原草稿保持，显式确认后才切换视图。三项修复已通过独立源码复核，15 个端到端场景重新通过。

OS 通知展示、托盘交互、登录启动及系统拖动手感不属于本次补验已通过项。
