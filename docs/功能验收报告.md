## 检查结论

F01—F33 均有实现入口。本轮逐项检查修复了原子保存、旧草稿冲突覆盖、重复通知、日期边界和操作入口等遗漏，并补充真实 SQLite 与浏览器回归测试。**业务与界面自动化通过，macOS 核心原生流程通过；系统集成尚不能宣布全部实机验收完成。** 解锁后已完成三级任务、月历、浮窗勾选同步与折叠、原生文件导入导出、备份恢复、关闭驻留、单实例及退出重启验证；实机发现的原生确认框、Esc 冒泡和折叠状态覆盖问题已修复。通知投递、自启、全局快捷键实际触发、托盘菜单、Spaces/多屏及 Windows 仍须目标机验收。

## 本轮修复的关键差距

1. 重复编辑由两次先后提交改为任务内容、规则和模板的同一事务；无效规则不会留下已修改的标题。编辑器固定原版本号，收到外部刷新后仍拒绝旧草稿覆盖，提供显式重新基于最新版本提交；移动面板同样保留位置草稿并加载最新任务树后确认重试，全局读取重试明确命名为“重新加载任务”。
2. 倒计时同周期启停不再重发提醒；专注截止瞬间暂停不再丢失结束提醒；补齐时区/DST、普通提醒 UTC 保持与重复提醒本地时分重排。
3. 增加菜单排序、任意合法父任务选择、改期面板、提醒清除确认、对话框快捷提交、输入法保护和关闭焦点归还。
4. 完整 JSON 可恢复只有倒计时/专注而没有任务的数据；加强引用/规则/设置校验，恢复活动专注的调度记录；不把 OS 快捷键注册配置当成可移植数据恢复。
5. 复制使用源选区首日作为锚点，首日没有任务也不会丢失日期偏移；导入显示相似项提醒。数据文件 URI 正确转义中文、空格、`#`、`?` 等路径字符。
6. 恢复先展示校验后的备份时间及节点数量，再确认；维护期间广播阻塞操作。补齐输入期间不贴边隐藏、离屏窗口回收和折叠位置重置。
7. macOS WKWebView 未提供浏览器 `confirm()` 面板，原先需要确认的操作会直接取消。统一改为等待 Wails 原生确认，绑定发起窗口；Esc 取消，不设置默认确认，重复点击不会复用另一操作的许可。桥接失败安全取消并在既有错误区域提示，允许重试。
8. 浮窗任务菜单摘要及子任务输入的 Esc 只取消当前操作，阻止事件冒泡隐藏窗口；取消子任务后恢复到父任务焦点。
9. 窗口移动/尺寸事件原先会以旧快照覆盖刚修改的折叠、层级和不透明度。新增锁内仅合并几何的保存路径，原生折叠/展开状态和按钮更新复测通过。

## 界面收尾复核

本轮检查了移动父任务、重复编辑、事项倒计时、编辑冲突、360×480 最小主窗口和 1080×760 月历的有效截图。独立复核指出的“移动冲突无法在面板内恢复”和“全局重试文案与动作不符”均已修复，重试流程也加入真实 SQLite E2E。最终判定 `disposition: ship`，范围仅为这两项修复及其可见回归检查，不扩展为原生系统或全业务验收结论。既有 DESIGN.md 与 token sidecar 经只读核对，无实质视觉漂移。

原生续验修复再次进行限域复核：Esc 修复 resolved；确认桥初审指出的失败无提示问题已补齐安全取消、可见错误与重试测试，复核 `disposition: ship`，范围仅限这些交互修复及既有截图回归，不扩展为系统能力全项通过。
