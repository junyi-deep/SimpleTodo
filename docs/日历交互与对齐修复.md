# 日历交互与对齐修复

本轮规则优先于早期日历摘要最多 3/12 条、日历点击只展示日期列表及批量选择框旧间距的说明。

- 批量选择框使用与完成框相同的 16×15px 尺寸与边界风格，顶部偏移改为 9px；展开箭头、标题、完成进度和操作区统一到 23px 首行。根任务、叶节点及展开的父任务保持同一中心线，长标题换行不把选择框移到整棵任务树中间。
- 月/周日历展示每一天全部已加载的根任务，移除 3/12 条截断和“+N 项”。任务区在日期格内独立滚动，不撑大日期格；发生溢出时显示持久的滚动轨道和滑块，避免 macOS 自动隐藏系统滚动条。支持滚轮、轨道点击、滑块拖动及方向键/PageUp/PageDown/Home/End；无溢出时隐藏轨道。
- 日历任务条使用蓝底白字（普通 #2563eb、悬停 #1d4ed8、完成 #4064a5 并带删除线）；非当前月只弱化日期数字，保持任务条可读。
- 拖动普通任务到另一日期可改期，沿用指针预览、Esc 取消、事务保存与整棵子任务树继承日期。保留原有提醒改期校验；重复实例仍由详情规则控制，拖动禁用且有悬停说明。拖动结束不会误触详情。
- 点击日期打开当天任务清单；点击日历中的任务条或抽屉清单中的具体任务，在同一抽屉内显示完整编辑表单。保存/取消或 Esc 返回当天清单，外层关闭按钮关闭抽屉；保留描述、日期、提醒、重复规则、草稿离开确认、版本冲突和显式重试。普通清单仍保持单击原位编辑。
