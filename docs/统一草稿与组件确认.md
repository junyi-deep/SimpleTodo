# 统一草稿与组件确认

本轮规则优先于旧文档中的专用子任务输入框、原生确认框及完成项拖动行为。

- 主任务、子任务和同级任务使用同一原位标题草稿。Shift+Enter 在父任务的可见后代末端打开子任务草稿；不再出现专用提示输入栏、箭头和关闭按钮。Enter 保存并继续同级，失焦保存，空白失焦或 Esc 自动取消。保留五层限制、输入法组合保护、冲突保护和可选 Tab 连续录入。保存过程中按 Esc 会停止继续创建下一条草稿。
- 清单中仅未完成任务允许拖动；完成项隐藏拖动手柄并禁用拖动事件。未完成任务保留预览、同级排序和分支移动。拖动结束前先保存标题草稿，提前捕获落点和来源，避免异步保存后事件目标失效。
- 移除描述、标题、日期、搜索、代理等字段和按钮的黑色外轮廓；输入聚焦用细灰边框，按钮保留柔和底色，主按钮保留内部细线以便键盘辨认。
- 所有应用内确认共用 `ConfirmDialog`。放弃修改、恢复、迁移、专注结束、重复影响确认和退出等操作不再调用 Wails 原生 Question 或浏览器 confirm。组件弹窗覆盖当前窗口中的内容，默认聚焦“取消”；Esc 和取消返回 false，确认后才执行操作，不复用另一个问题的批准。保留焦点返回、减少动态效果与浮窗边缘隐藏保护。
- 按用户确认，文件选择、保存位置和日期选择器保留系统实现。
- 调整计划日期弹窗提供每日/每周/每月重复、间隔、星期和可选结束日期；留空一直重复。每周首次发生日期取计划日期及以后第一个选中星期。日期移动和重复规则在同一数据库事务提交，校验失败不会只保存日期。
- 双箭头是重复任务状态标识，补充了完整悬停说明和可访问名称。全部系统时区说明标签与时区变更提示已移除，后台时区计算仍负责正确安排提醒。

## 验证

- Playwright 54 项全部通过，包含新增 8 项专项：子任务空白取消/失焦保存/连续同级录入、完成项禁止拖动、组件确认的取消/确认/默认焦点、描述无黑框和时区标签移除、改期创建重复、编辑中拖动先保存、400px 深色确认框、浅深主题已选/未选星期与完成框的键盘焦点、关闭重复后的隐藏字段处理。
- Vitest 9 项通过，确认模型覆盖重复请求拒绝、取消、旧组件卸载不干扰新问题及浏览器预览不用原生确认。
- Go 全套测试与 go vet 通过；新增改期和重复规则同事务保存与失败回滚测试。
- 前端类型检查和生产构建通过；macOS arm64 应用包构建及临时签名验证、Windows amd64 生产编译通过。
- 本轮原生补验受 Mac 锁屏限制，不能以浏览器测试代替原生结论。

独立界面复核中提出的键盘焦点可辨性问题已通过细内线修复；复核结论为该项已解决（ship，限定于该项修复复核范围），未扩展为原生验收结论。
