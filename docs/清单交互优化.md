# 清单交互与桌面窗口优化

本次需求优先于旧版交互设计。任务仍统一保存在 `tasks` 表，未新增独立子任务表。

## 窗口与图标

- 新窗口默认 480×720，最小 400×440；已保存的用户窗口尺寸继续保留。月/周日历仍在原窗口内放大，返回清单恢复尺寸。
- Windows 使用无原生标题栏的窗口，顶栏支持拖动，并包含任务列表、日历、计时、固定、最小化、放大/还原和关闭；关闭后驻留托盘。
- macOS 保留交通灯，界面控件不参与窗口拖动。
- 蓝底白色交叉双对钩，短笔画交叉。几何源文件为 `build/appicon.svg`，派生应用图标、Icon Composer、Windows ICO、macOS ICNS 和托盘模板；关于页共用该图形。

## 清单

- 搜索放在左侧，完成统计放在固定 footer。移除隐藏已完成的图标。
- 单击选中，长标题换行；双击或选中后 Enter 在原位置编辑标题，Enter/失焦保存，Esc 取消。保存使用原任务树版本，冲突保留草稿并显示错误。
- 右侧铅笔打开主窗口内的详细设置对话框，保留描述、日期、提醒、重复、延期、影响范围确认与版本冲突处理；不创建新原生窗口。
- 底部只有居中加号。点击添加草稿行并自动聚焦；空白失焦或 Esc 不写入数据库。输入后 Enter 或失焦保存，保留输入法保护与多行粘贴导入。
- 点击“选择”后，右侧显示完成、未完成、删除三个图标；无选中项时禁用。批量执行仍先预览影响范围。
- 拖到任务中央作为子任务，边缘调整顺序；支持整个分支跨根移动。移动在单一事务中检查列表版本、防环、树容量和重试幂等。移动独立根任务会继承目标根的日期/提醒；如原任务有说明，先确认再把说明追加到目标根，避免丢失内容。原提醒取消；重复任务仅移动本次实例，保留跳过标记避免重新生成本次。

## 提醒、默认设置与更新

- 提醒气泡支持不重复、每日、每周、每月，以及间隔、星期、截止日期。新重复以所选提醒日期为起点；现有系列的后续修改会显示影响范围并确认，停止系列仍通过详细设置执行。
- 新数据库默认开启未完成自动延期；已有用户显式保存的关闭偏好继续保留。
- 首次初始化默认注册登录启动，注册结果反映系统真实状态，失败提示可重试。用户在设置中关闭后，不会在下次启动自动覆盖。
- 删除自定义项目发布页地址。用户手动检查时请求固定的 GitHub Release API，比较稳定版并匹配 `macos-arm64` 或 `windows-amd64` 压缩包。下载直接指向该 Release 附件，不上传待办内容，不自动安装。

- Go/SQLite：33 个 Go 测试及 `go vet ./...` 通过，`internal/...` 竞态检查通过。覆盖分支跨根移动、说明保留/溢出回滚、重复实例标记、版本冲突、幂等及循环拒绝，以及默认设置、平台发布包选择和版本比较。
