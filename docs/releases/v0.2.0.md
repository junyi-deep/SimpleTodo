# SimpleTodo v0.2.0

这一版完善本地工作区，并统一了列表、日历、专注、设置和复盘的界面。

## 新增与改进

- **专注任务搜索**：在关联任务下拉框中输入关键词筛选、选择任务，支持中文、大小写不敏感搜索和方向键／Enter；保留自由专注。
- **独立窗口**：列表、日历、专注、设置和复盘可以同时使用，各自记住窗口大小、位置和显示状态。
- **按时间安排任务**：以开始与可选结束时间控制任务范围，每天独立勾选；未完成自动延期会延长结束时间，保留历史记录。
- **标签与筛选**：预置重要、紧急，支持新建、多选、排序和过滤；选中任务时，已分配标签会在标题下即时显示。
- **日历与甘特图**：控制是否显示子任务，在甘特图上拖动调整起止时间，在日期抽屉内直接处理任务。
- **复盘与本地笔记**：完成热力图、状态饼图、趋势与标签分布；任务总览支持日期、状态、标签搜索多选与内容过滤，配合可调整分栏的 Markdown 笔记。
- **自动更新与备份**：启动及每小时检查更新，可立即更新或跳过版本；自动、手动与保护备份合计保留最近 3 次。
- **界面细节**：统一浅深主题、字体、图标、间距、浮层和焦点反馈；任务操作默认灰色，悬停时显示对应语义色。
- **交互修复**：改进任务排序、层级调整、子任务录入、确认弹窗、标签选择和窗口恢复。

任务和笔记仍保存在本机，无需账号。升级时会自动迁移本地数据结构，并在迁移前创建保护备份。

## 下载

- macOS Apple Silicon：`SimpleTodo-macos-arm64.zip`
- Windows 64 位：`SimpleTodo-windows-amd64.zip`

macOS 压缩包解压后将应用放到“应用程序”；Windows 解压后运行应用。当前发布包未配置开发者证书签名。
