# SimpleTodo v0.2.2

修复 [issue #7](https://github.com/junyi-deep/SimpleTodo/issues/7)。

- 修复任务标签选择框被任务列表裁切的问题。弹层根据窗口边缘调整位置，选项独立滚动，保留搜索、多选和新增；日历抽屉内也可正常使用。
- 标签支持填充颜色，可在“设置 → 标签”选择八种颜色。颜色会保存到本机，并随 JSON 导出和数据库备份保留。
- 日历与甘特图增加“已完成”开关，默认隐藏已完成任务，主任务与子任务都适用；选择会记住，且不影响日计划或收集箱的过滤状态。

首次启动会在数据库迁移前创建保护备份，任务和笔记保持不变。

提供 macOS Apple Silicon 和 Windows 64 位压缩包。完整实现与验证范围见 [标签与日历过滤修复](../issue7-标签与日历过滤.md)。

验证：94 项界面回归通过（官网截图生成用例按需运行）；10 项前端单元测试通过；Go 测试、静态检查、任务引擎竞态检查和本机 macOS ARM64 打包通过。
