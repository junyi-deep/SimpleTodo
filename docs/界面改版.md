# 单窗口极简改版

后续 [清单交互优化](清单交互优化.md) 优先：标题双击原位编辑、详细设置对话框、加号草稿、固定底部统计等以新文档为准。

日期：2026-10-21。本次用户明确修改优先于原功能设计中的多窗口、颜色、未完成页签及底部录入规则。

- 所有工作视图在唯一主窗口中切换；日历扩大当前窗口，返回任务列表恢复列表尺寸。移除独立总览、今日待办浮窗和快速记录窗口。托盘/全局快速记录回到主窗口并聚焦列表输入。
- 黑白灰主题、紧凑任务行；移除品牌对钩、本地徽标、底部数据说明和颜色配置。历史数据中的颜色字段保留兼容，新建/编辑不再设置颜色。
- 收集箱显示所有任务，包括有日期、未安排日期和已完成任务；日计划按所选日期筛选。移除所有未完成页签。所有原生 select 替换为统一自定义下拉，支持键盘和可访问性角色。
- 月/周日历共用同一窗口。点击日期打开右侧任务抽屉，宽度 360—480px；Esc 或点外部关闭。下方不再重复展示任务列表。
- 任务新增行位于任务列表末端；Enter/Shift+Enter 继续使用。详情在对应任务行下展开，保留描述、日期、重复、延期与冲突处理。
- 更多菜单移除“编辑、添加子任务、复制、上移、下移”；编辑和子任务通过 Enter/Shift+Enter，排序通过拖动。拖动提供任务预览与落点反馈。
- 任务标题单行省略、悬停显示完整内容；提醒图标在更多菜单左侧悬停出现，气泡内设置时间，已设提醒在任务下显示小字。
- README 面向使用者，仅介绍完全本地、极简和主要功能，并提供两张实际截图。
- 公开仓库使用当前 GitHub 账户下 SimpleTodo；标签推送流水线只构建 macOS arm64 和 Windows amd64，生成两个压缩包并发布 Release。手动运行仅验构建，不发布。
