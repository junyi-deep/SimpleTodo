# 任务录入一致性

## 完成任务继续处理

已完成主任务仍可单击修改标题，通过任务设置编辑详情，也可用 Enter 添加同级任务、Shift+Enter 添加子任务。编辑标题保留完成状态；新增未完成子任务后，父任务和祖先自动变为未完成，原有已完成子任务保持完成。新子任务未输入内容即取消时，不改变原任务状态。

## 日历日期抽屉

日期抽屉和主列表复用 `TaskList`、`TaskTree`、`InlineTitle`：加号新增到当前选定日期，单击就地编辑，Enter 连续添加同级任务，Shift+Enter 添加子任务。完成、提醒、改期、删除等既有操作沿用同一任务行。

任务设置图标进入抽屉内的详细编辑器；点击日历网格任务条仍直接查看详情。

## Shift+Tab 提升层级

任务行自身聚焦或标题编辑时，Shift+Tab 将整个分支提升一级。标题编辑先保存；保存失败则保留草稿，不移动任务。直属子任务提升为主任务，保留任务 ID、日期及后代。新主任务插在原主任务之后，原任务的其他后代仍归原任务。已完成任务也可键盘提升，完成状态保持不变；拖动仍仅适用于未完成任务。

行内完成、设置、删除等操作按钮的 Shift+Tab 保持普通反向焦点导航，避免意外改层级。根任务不继续提升。

## 同级草稿位置

在任务 A 上按 Enter，同级任务 B 的草稿位于 A 及其全部可见后代之后，缩进与 A 相同。提交仍以 A 为同级插入锚点，不以最后一个后代作为父任务。连续输入 B、C 时保持同级顺序。
